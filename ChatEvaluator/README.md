# ChatEvaluator

Дополнительная независимая проверка соответствия вакансии перед подачей заявки.
Модуль отправляет ссылку на выбранную вакансию в существующий диалог ChatGPT
через Playwright и возвращает полученный ответ для отображения в JavaFX GUI.

В этом диалоге уже накоплены знания об опыте, предпочтениях и обстоятельствах
пользователя. Цель — получить второе мнение с этим контекстом в дополнение
к анализу Codex в Seeker. Новый запрос к Codex или API без истории диалога
не заменяет этот сценарий.

ChatEvaluator находится рядом с Applier: оценка вакансии и подготовка формы —
отдельные действия. Для подключения к браузеру используется существующий
`ManagedBrowser` из Applier.

Документация для реализации и пошагового ревью:

- [REQUIREMENTS.md](REQUIREMENTS.md) — поведение и границы задачи.
- [ARCHITECTURE.md](ARCHITECTURE.md) — минимальное устройство модуля.
- [PLAN.md](PLAN.md) — порядок реализации с обязательной остановкой после каждого пункта.

Ссылка на выбранный пользователем диалог сохранена в локальном файле
`Data/chat_evaluator/config.properties`, настройка `chat.url`.
Это рабочий диалог. Для всех живых проверок и отладки используется отдельный
тестовый диалог, предоставленный пользователем; его ссылка сохранена в том же
локальном файле под ключом `chat.test.url`. Модуль читает только `chat.url`.

Перед явно запрошенной живой проверкой временно установить значение
`chat.test.url` в `chat.url`, сохранив рабочее значение, и сверить адрес открытого диалога.
После проверки восстановить рабочее значение, в том числе при ошибке.
Правила оценки и контекст в тестовом диалоге пользователь подготавливает
заранее; модуль отправляет только URL вакансии.

Автоматические тесты — только юнит-тесты без браузера, реальной сессии
и отправок в ChatGPT. Интеграционные тесты с реальным диалогом не добавлять
и не запускать, включая тестовый диалог. Живые проверки выполняются отдельно
по явному указанию пользователя; обычное ревью не запускает GUI или диалог.

Кнопка `GPT Eval` располагается рядом с `Apply`. Полученный ответ целиком
показывается в отдельном окне; сохранение результата сейчас не требуется.

Вопрос входа в ChatGPT в управляемом браузере отложен до живой проверки.
Способ входа предстоит определить с пользователем, когда он действительно
понадобится; заранее реализовывать механизм логина не нужно.
