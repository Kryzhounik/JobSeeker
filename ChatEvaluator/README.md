# ChatEvaluator

Модуль получает дополнительную оценку вакансии через существующий диалог
ChatGPT, в котором уже есть контекст пользователя. Он отправляет только
ссылку на вакансию и возвращает полный текст нового ответа.

## Как работает

Модуль проверяет доступность вакансии и приём заявок. Если LinkedIn
ограничивает обычный HTTP-запрос, проверка выполняется через браузер
с существующей сессией пользователя.

Затем модуль отправляет ссылку в выбранный диалог ChatGPT и ждёт завершения
ответа именно на это сообщение. Браузер и история диалога сохраняются.

В JavaFX GUI оценка запускается кнопкой `GPT Eval`; ожидание идёт в фоне,
остальные действия остаются доступны. Полный ответ сохраняется за исходной
вакансией и показывается в отдельном окне; ход работы и результат видны
в панели фоновых процессов. Одновременно выполняется одна оценка.
Оценка не меняет статус и оценки вакансии и не запускает подачу заявки.

Для диагностики есть минимальный CLI, использующий тот же сценарий без GUI.
Для обычной ручной оценки проще открыть сам диалог ChatGPT.
